Elice HR Assignments (최재훈)

실제 질의마다 쌓이는 지표의 누적 평균과 95% 구간, 최근 50건 이동 평균, 같은 구성의 Gold Set 기준선. "참고값"은 검증 조건을 통과하지 못한 지표다.

연결 중
    누적 평균 95% 구간 최근 50건 Gold Set 기준선

    연결하면 지표가 표시된다.

    최근 질의최신 100건까지, 페이지당 10건. 질문과 답 원문은 표시하지 않는다

    표 읽는 법
    • 검색 단계 거절: 질문과 충분히 비슷한 문서를 찾지 못해(검색 최고 점수가 임계값 미만) LLM을 부르지 않고 바로 거절
    • 생성 단계 거절: 문서는 찾았지만 LLM이 답할 근거가 부족하다고 판단해 거절
    • 근거: 답의 모든 주장이 검색된 문서로 뒷받침되면 통과, 아니면 실패(Judge 채점, 참고값)
    • CP: Citation Precision. 답에 단 인용 가운데 그 문장을 실제로 뒷받침하는 인용의 비율(Judge 채점, 참고값)
    • 대기는 아직 채점 전, -는 거절된 질의처럼 채점 대상이 아님
