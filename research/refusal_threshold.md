# 거절 임계값 보정

상태: 확정(**임계값 0.6375**, dense 최고 코사인 유사도). 답 있는 문항의 오거절 0%(두 언어), 답 없는 문항 거절 영어 4/8, 한국어 5/8.

## 질문

검색 단계에서 LLM을 부르지 않고 거절할 dense 최고 점수 임계값은 얼마인가.

## 거절 판정 구조

1. 검색 단계: dense 최고 점수(코사인 유사도)가 임계값 미만이면 LLM을 부르지 않고 `insufficient_context`로 답한다. 검색 방식(dense, hybrid)과 상관없이 dense 점수로 판정한다. RRF 점수는 순위 기반이라 임계값을 둘 수 없고, Part C에서 검색 방식만 바꿨는데 거절 동작까지 바뀌면 변인이 둘이 된다.
2. 생성 단계: 임계값을 넘은 문항은 LLM에 보낸다. 근거에 답이 없으면 모델이 근거 부족 토큰(`INSUFFICIENT_CONTEXT`)만 내도록 지시하고, 이 토큰이 나오면 거절한다.

임계값은 1차 필터다. 오거절(답 있는 문항을 거절)은 사용자에게 바로 손실이지만, 미거절(답 없는 문항을 통과)은 2단계가 한 번 더 거른다. 그래서 오거절을 먼저 묶는다.

## 고정한 변인

| 변인 | 값 |
|---|---|
| 임베딩 | Qwen3-Embedding-0.6B(7단계 확정) |
| Chunking | `structure-512-77`(6단계 확정) |
| 검색 | Qdrant 정확 검색, dense top-1 점수 |
| 질의 | dev set 38문항(답 있음 30, 답 없음 8), 영어와 한국어 각각 |

## 판정 규칙(실험 전에 정함, `pick_threshold`로 구현)

1. 후보는 0과, 관측한 점수를 정렬했을 때 이웃한 두 점수의 중간값들이다. 점수가 후보 미만이면 거절한다.
2. 답 있는 문항의 오거절 비율이 **영어, 한국어 각각** 5% 이하인 후보만 남긴다. 30문항에서 5%는 1.5문항이라 언어마다 최대 1문항이다. 두 언어를 합쳐 재면 한 언어의 오거절을 다른 언어가 덮을 수 있어 따로 지킨다.
3. 그중 답 없는 문항을 가장 많이 거르는 후보, 같으면 낮은 값(오거절 위험이 작은 쪽)을 고른다.

## 해석

- **임계값으로 거를 수 있는 것은 주제가 문서 밖인 질문이다.** 거절된 문항은 Kubernetes 오토스케일러, Sonatype Nexus 정리 정책, Astral 인력, uv 기본 동시 다운로드 수 같은 질문이다. 질문 어휘가 문서와 덜 겹쳐 최고 점수가 낮다.
- **문서 주제와 가까운 함정형 답 없음 문항은 임계값을 넘는다.** 영어에서 통과한 4문항은 Conda 지원 시점(0.706), M4 Max 메모리 비교(0.701), HTTP 타임아웃 기본값(0.737), GitHub 필수 검사 설정(0.726)이다. 모두 uv 문서에 가까운 주제(Python 환경, 벤치마크, 환경변수, GitHub Actions)가 있어 점수가 답 있는 문항 중간과 같다. 이 문항들은 점수로 가를 수 없고 생성 단계의 근거 부족 토큰이 거른다.
- **0.6375에서 오거절 0%를 넘지 않고 더 거를 수 있는 여유가 없다.** 다음 후보(0.6574)부터 한국어 답 있는 문항(0.649, 사실형)이 거절된다. 규칙상 0.6574도 상한(5%) 안이지만 답 없음 거절이 늘지 않아 낮은 값을 골랐다.

## 결정

**임계값 0.6375.** dense 최고 코사인 유사도가 0.6375 미만이면 LLM을 부르지 않고 `insufficient_context`로 답한다. 이 값은 이 임베딩(Qwen3-Embedding-0.6B)과 Chunking(`structure-512-77`)에서만 유효하다. 둘 중 하나가 바뀌면 다시 보정한다.

## 다음 단계에 주는 영향

- **9단계(LLM 선정)**: dev set 답 없는 문항 16개(영어 8, 한국어 8) 중 7개는 검색 단계를 통과한다. LLM 후보의 거절률은 이 7문항과, 임계값 근처의 답 있는 문항에서 갈린다.
- **10, 11단계**: test set에서 오거절 비율을 다시 잰다. dev set의 여유가 작아 오거절이 생길 수 있다(아래 한계).

## 한계

- **여유가 작다.** 임계값과 가장 낮은 한국어 답 있는 문항의 차이는 0.011이다. test set에서 점수가 조금만 낮은 답 있는 문항이 나오면 오거절이 된다. test set의 오거절이 5%를 넘으면 그 결과를 Part C에서 다룬다(임계값을 0.62대로 낮추면 답 없음 거절은 영어 0.500, 한국어 0.500으로 줄어든다).
- 답 없는 문항이 언어마다 8개라 거절 비율의 한 칸이 0.125다.
- 점수는 Qdrant 정확 검색의 코사인 유사도다. 운영 검색이 HNSW 근사 검색이면 최고 점수가 같거나 조금 낮을 수 있다(근사 검색은 최고 청크를 놓칠 수 있다).

make refusal-calib   # Qdrant 기동, 확정 구성으로 색인, dev set 76문항 점수 측정, Qdrant 정지(CPU에서 약 6분)
