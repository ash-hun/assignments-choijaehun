## 실시간 평가 대시보드

**목적**: 서비스가 실제 질의를 받는 동안 품질과 운영 지표가 어떻게 변하는지, Gold Set 기준선에서 얼마나 떨어져 있는지 본다.

**데이터 출처**: 화면이 `GET /v1/metrics/stream`(SSE)에 연결해 `snapshot` 이벤트를 받을 때마다 다시 그린다. 서버는 기록이나 판정이 늘 때마다 보낸다. 페이지 HTML 자체에는 데이터가 없다.

### 구성

| 영역 | 내용 |
|---|---|
| 연결 막대 | API 키 입력(비밀번호 칸), 연결 버튼, 연결 상태 문구(연결 중, 연결됨, 연결 실패(상태 코드), 연결 끊김) |
| 요약 칸 | 질의 수, 답한 질의 수, Judge 판정 수, Judge 비용 / 상한, 구성(`config_id`), 기준선 실행(run_id 또는 없음) |
| 범례 | 누적 평균(선), 95% 구간(띠), 최근 50건(선), Gold Set 기준선(점선) |
| 지표 카드 | 지표마다 하나. 제목, 참고값 표시(해당 시), 현재 값 한 줄(누적 [구간], 최근, 기준선), 차트(x축 표본 수, y축 값) |

지표 카드 순서: 거절률, 검색 최고 점수가 임계값 ±0.05 안, Latency(답한 질의), TTFT(답한 질의), 질의당 비용, 근거 없는 주장 없음(참고값), Citation Precision(참고값).

### 상태

| 상태 | 보이는 것 |
|---|---|
| 처음 열었을 때 | 저장된 키로 바로 연결을 시도한다. 연결 전 지표 영역에는 "연결하면 지표가 표시된다." |
| 기록 0개 | 요약 칸은 0, 지표 카드마다 "아직 값이 없다" |
| 판정 0개 | Judge 지표 카드만 "아직 값이 없다". 나머지는 그려진다 |
| 기준선 없음 | 요약 칸 "기준선 실행: 없음", 카드의 기준선 "-", 점선 없음 |
| Judge 예산 소진 | 요약 칸에 경고 "Judge 예산 소진: 채점을 멈췄다. 기록은 계속 쌓인다." |
| 401(키 틀림, 누락) | 상태 문구 "연결 실패(401)". 지표는 이전 그대로 |
| 503(실시간 평가 꺼짐) | 상태 문구 "연결 실패(503)" |
| 서버 종료, 네트워크 끊김 | 상태 문구 "연결 끊김". 연결 버튼으로 다시 연결 |

### 동작

- 연결 버튼은 이전 연결을 끊고 새로 연결한다.
- API 키는 이 탭의 `sessionStorage`에만 남는다. 저장소를 쓸 수 없는 환경(사생활 보호 창 등)에서도 연결은 된다.
- `EventSource`는 헤더를 실을 수 없어 `fetch` 스트림으로 SSE를 읽는다.
- 화면 폭이 좁으면 카드가 한 줄에 하나로 내려간다. 밝은 화면과 어두운 화면 설정을 따른다.

### 보안

- 모든 값은 `textContent`와 SVG 속성으로만 넣는다. `innerHTML`을 쓰지 않는다. 질문 원문과 답 원문은 화면에 없다.
- 외부 스크립트, 폰트, CDN을 쓰지 않는다. 차트는 SVG를 직접 그린다.
- 페이지는 인증 없이 열리지만 데이터는 `/v1/metrics/stream`의 API 키 검사를 거친다.
