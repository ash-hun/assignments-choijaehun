# 11. 생성 성능 평가

**결론: 확정한 전체 파이프라인의 uv 답변 정확성(답한 문항 중 정답 비율)은 영어 0.742, 한국어 0.607이다.** 답 없는 문항은 모두 거절했고, 답 있는 문항을 거절한 비율은 영어 3.1%, 한국어 9.7%다. 정답을 놓친 주된 원인은 다중 문서 문항의 검색 누락과, 생성 출력 상한(1,500토큰)에서 답이 잘린 경우다. 이 값이 Part C의 기준선이다.

## 질문

확정한 파이프라인의 답이 정답 기준을 담는가, 근거가 없을 때 거절하는가.

## 고정한 변인

| 변인 | 값 |
|---|---|
| 파이프라인 | 10단계와 같은 실행(`baseline-4e6abaee3113`). 같은 기록에 Judge를 붙였다 |
| 질의 | test set 영어 40, 한국어 39(1문항은 게이트웨이 WAF 차단, 10단계 참고) |
| Judge | gemini-3.8-flash, 인용 프롬프트 v3, 루브릭 v2, 표본 3회 다수결 |

## 지표

채택 지표는 검증(파일럿, 타당성 검증, 3회 일치, 사람 라벨 20건 대비 kappa)을 통과한 것만이다. 검증 과정과 결정은 [research/gold_metric_selection.md](../../research/gold_metric_selection.md)의 "파일럿"부터 "품질 점수와 Citation Precision 구성 확정"까지에 있다.

| 지표 | 상태 | 근거 |
|---|---|---|
| uv 답변 정확성 | 채택 | 무작위 청크에서 0.719 하락, 3회 일치 1.000 / 0.964, kappa 0.886 |
| Refusal Accuracy | 채택(규칙) | 거절을 끈 변형에서 1.000 하락 |
| Citation Precision | 참고값 | 반응성은 확인. 사람 대비 kappa 0.494(사람 라벨 126개 중 반례가 1개뿐인 kappa 역설, 일치율 0.984) |
| 품질 6항목 | 참고값 | 5항목은 기준선 통과율 1.000(변별력), "근거 없는 주장 없음"은 3회 일치 0.839 / 0.821 |

| 유형 | 영어 | 한국어 |

| trap | 0.750 (4) | 0.750 (4) |

## 해석

- **다중 문서 문항이 가장 약하다.** 10단계에서 multi_doc은 두 문서 중 한쪽 근거만 찾은 문항이 많았다. 근거를 못 받은 쪽의 요점은 답에 들어갈 수 없다. 한국어 multi_doc 정확성은 0.333이다.
- **답 잘림이 정답을 깎는다.** 답한 59건 중 8건이 출력 상한(1,500토큰)에서 잘렸고 그중 1건만 정답이었다. 잘리지 않은 51건의 정확성은 0.765다. 요약과 다중 문서 문항이 길어서 잘린다.
- **답한 문항의 인용은 대체로 맞다.** Citation Precision이 0.94 이상이다. 정답을 놓친 원인은 잘못된 인용보다 근거 누락과 잘림이다.
- **한국어는 검색과 거절 양쪽에서 손해를 본다.** 오거절이 3배이고(0.097, 품질 하한 10% 근처), 정확성도 0.135 낮다. 다만 언어별 구간이 겹쳐 차이가 있다고 판정할 수 없다.

## Part C에 주는 단서

| 관찰 | 후보 |
|---|---|
| multi_doc 검색 누락, trap의 낮은 nDCG(10단계) | Hybrid 검색(dense + BM25) |
| 답 잘림 8건(14%) | 생성 출력 상한 조정 |
| 한국어 오거절과 검색 손해 | 한국어 질의 번역 |

## 한계

- 사람 라벨은 작성자 한 명, 20건이다. 라벨러 사이의 일치도는 재지 않았다.
- 한국어 답도 영어 정답 기준과 대조한다.
- 표본 3회 다수결이라 Judge 자체의 오차는 신뢰구간에 들어 있지 않다.
- 유형별 값은 문항이 4~11개라 경향으로만 읽는다.
