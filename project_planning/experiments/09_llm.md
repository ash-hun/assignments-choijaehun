# 9. LLM 선정

**결론: claude-haiku-5-5**(엘리스 ML API Serverless). 두 후보 중 품질 하한을 넘은 유일한 모델이고, 비용과 지연도 가장 낮다.

## 질문

품질 하한을 넘는 생성 모델 중 비용이 가장 낮은 것은 무엇인가.

## 후보

| 모델 | 입력 단가(100만 토큰) | 출력 단가(100만 토큰) | 비고 |
|---|---|---|---|
| claude-haiku-5-5 | ₩141 | ₩708 | |
| gemini-3.8-flash | ₩1,063 | ₩5,315 | 답 전에 추론 토큰을 쓰고, 추론 토큰도 출력으로 과금된다 |

단가는 VAT 별도다. 두 모델 모두 temperature 0을 받고 `seed`는 거부해서, temperature 0으로 문항당 한 번 호출했다. 앞 단계에서 쓴 `gpt-6.1-terra`는 temperature를 기본값(1) 외에는 받지 않아 같은 조건으로 비교할 수 없어 뺐다.

## 고정한 변인

- 검색: Qwen3-Embedding-0.6B, `structure-512-77`, dense 상위 5개(6, 7단계)
- 거절 1단계: dense 최고 점수 0.6375 미만이면 LLM을 부르지 않음(8단계)
- 프롬프트: 8단계의 `prompt_builder`
- 질의: dev set 76문항(영어, 한국어 각 38). 검색 단계에서 9문항이 거절돼 67문항을 LLM에 보냈다

## 판정 규칙(실험 전에 정함)

1. 형식 준수율 95% 이상, 답 있는 문항 오거절 10% 이하를 영어, 한국어 각각 만족하는 후보만 남긴다.
2. 그중 문항당 평균 비용이 가장 낮은 후보를 고른다.

형식 준수는 거절이면 `INSUFFICIENT_CONTEXT`만 냈는지, 답이면 유효한 `[n]` 인용이 하나 이상 있는지로 본다.

## 결과

| 모델 | 언어 | 형식 준수 | 오거절(답 있음) | 거절(답 없음) | 문항당 비용 | 지연 평균 / p95 |
|---|---|---|---|---|---|---|
| **claude-haiku-5-5** | 영어 | 1.000 | 0.033 | 1.000 | ₩0.79 | 3.2초 / 5.5초 |
| **claude-haiku-5-5** | 한국어 | 1.000 | 0.000 | 1.000 | ₩0.94 | 3.7초 / 6.7초 |
| gemini-3.8-flash | 영어 | 1.000 | 0.100 | 1.000 | ₩4.53 | 5.8초 / 11.5초 |
| gemini-3.8-flash | 한국어 | 1.000 | **0.133** | 1.000 | ₩4.86 | 5.9초 / 10.9초 |

- 두 모델 모두 인용 형식을 지켰고 근거에 없는 번호를 쓰지 않았다. 검색 단계를 통과한 답 없는 문항 7개도 모두 근거 부족 토큰으로 거절했다.
- gemini-3.8-flash는 한국어 오거절이 하한(10%)을 넘어 탈락했다. 오거절 7건 중 5건이 다중 문서 문항으로, 상위 5개 근거에 답의 일부만 있으면 전체를 거절했다.
- claude-haiku-5-5는 같은 문항에서 근거가 있는 부분만 답하고 나머지는 "문서에 없다"고 밝혔다.
- 실험 비용은 claude-haiku-5-5 약 ₩66, gemini-3.8-flash 약 ₩357이다(VAT 별도).

**근거 밖 내용 검토**: claude-haiku-5-5의 영어 답 중 위험이 큰 7문항(함정 5, 다중 문서 2)을 근거, 정답과 대조했다. 근거 밖 사실을 보탠 답은 없었고, 명령과 설정 키는 근거 그대로였다. 검토는 사람이 아니라 Claude(작업 에이전트)가 했다. 전수 판정은 11단계에서 Judge로 한다.

## 결정과 이유

규칙을 그대로 적용해 **claude-haiku-5-5**를 골랐다. 하한을 넘은 후보가 하나뿐이고, 비용은 약 5.4배 낮고 지연도 짧다.

## 다음 단계에 주는 영향

- Query 경로는 `LLM_MODEL=claude-haiku-5-5`로 띄운다. 문항당 약 ₩0.9, 지연 평균 3~4초다.
- Judge는 생성 모델과 다른 계열이어야 하므로 Anthropic 계열을 뺀다.
- 첫 토큰 지연은 스트리밍 호출이 필요해 Streaming 구현 때 잰다.

## 한계

- 후보가 둘이다.
- temperature 0이어도 출력이 완전히 같다는 보장은 없어 문항당 한 번만 호출했다. 응답은 캐시에 저장해 다시 돌려도 같은 답을 쓴다.
- 30문항이라 오거절 한 칸이 0.033이다.
